# Resource Policy

The canonical machine-readable policy is `config/resource_policy.yaml`. This document explains how to apply it.

## Allowed

Use official, open, and attributable sources:

- university course pages;
- author-posted lecture notes;
- arXiv papers;
- OCW material;
- official conference pages;
- publisher open access pages.

## Disallowed

Do not use:

- pirated textbook scans;
- unofficial PDF mirrors;
- homework solution dumps;
- paywalled excerpts copied from inaccessible sources;
- anonymous notes whose origin cannot be verified.

## Citation Practice

Each generated week should include source references in its YAML plan. Daily notes should cite sources when a specific theorem, definition, or reading assignment depends on them. Short summaries are acceptable; long copied passages are not.

## If a Source Is Unavailable

Do not invent a replacement citation. Use an allowed alternative, create a source-search task, or limit the output to prerequisite questions and a plan.
