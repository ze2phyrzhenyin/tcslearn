
# Proof Weaknesses

Initial watchlist:

- Quantifiers and domain restrictions.
- Using intuition as proof.
- Skipping assumptions.
- Not naming the induction hypothesis.
- Probability statements without a sample space.
- Big-O statements without declaring variables.

Week 2 proof-pattern watchlist:

- Algorithm correctness proof without specification.
- Loop invariant too weak to imply postcondition.
- Recursive correctness proof without base case.
- Decision-tree lower bound without model assumptions.
- Representation invariant stated but not used.
- Amortized analysis confused with average-case.
- BFS shortest-path proof without queue/layer invariant.
- Greedy proof without exchange argument.
- DP proof without state-order induction.
- Randomized proof without sample space, random variable, and bad event.
