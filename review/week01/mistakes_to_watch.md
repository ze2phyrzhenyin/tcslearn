# Week 1 Mistakes to Watch

1. Reversing quantifier order when translating a sentence.
2. Negating `forall x exists y` as `forall x forall y not`.
3. Forgetting to preserve variable domains during negation.
4. Treating converse as contrapositive.
5. Treating implication as causal language rather than logical condition.
6. Proving only one direction of set equality.
7. Using an element not in the declared universe for a counterexample.
8. Confusing image with preimage.
9. Assuming preimage requires an inverse function.
10. Proving injective by testing examples.
11. Proving surjective without checking the codomain.
12. Calling a relation equivalence after checking only symmetry.
13. Forgetting antisymmetry in partial orders.
14. Omitting the base case in induction.
15. Writing the induction hypothesis for the wrong predicate.
16. Using the conclusion for `k+1` inside the induction step.
17. Using ordinary induction when the recurrence needs earlier cases.
18. Treating structural induction as ordinary induction on integers without defining size.
19. Saying a recursive algorithm terminates because it is recursive.
20. Giving an invariant that is just the final postcondition.
21. Giving an invariant too weak to imply correctness at termination.
22. Mixing correctness proof with running time analysis.
23. Writing Big-O without saying the variable.
24. Treating Big-O as approximate equality.
25. Claiming `Theta` after proving only `O`.
26. Choosing Big-O constants that depend on `n`.
27. Ignoring recurrence base cases.
28. Applying Master theorem without checking its form.
29. Treating experimental timings as proofs.
30. Confusing ordered tuples with unordered subsets.
31. Forgetting whether repetition is allowed.
32. Double-counting overlapping cases.
33. Using pigeonhole without defining boxes.
34. Forgetting that a tree must be connected and acyclic.
35. Treating directed edges as symmetric.
36. Writing probability without a sample space.
37. Confusing independent and disjoint events.
38. Assuming linearity of expectation requires independence.
39. Using union bound as if it were equality.
40. Applying Markov to a random variable that may be negative.
41. Applying Hoeffding without boundedness or independence.
42. Forgetting that learning-theory probability is often over samples.
43. Treating norm as coordinate-wise absolute value.
44. Using Cauchy-Schwarz without naming the inner product.
45. Confusing convex with increasing.
46. Treating gradient intuition as a convergence proof.
47. Mixing up problem and algorithm.
48. Ignoring input encoding in complexity statements.
49. Reversing reduction direction.
50. Claiming a lower bound because a problem ``looks hard''.
