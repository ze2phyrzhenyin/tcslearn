# Week 2 Review

## Purpose

Week 2 is about algorithmic thinking, data structures, and proof patterns. Review is not rereading. It is a structured check of whether you can write specifications, proofs, and complexity analyses without being prompted.

## Review Checklist

1. Can I state an algorithmic problem before naming an algorithm?
2. Can I write input, output, precondition, postcondition, and input size for sorting, selection, BFS, and edit distance?
3. Can I prove a loop invariant with initialization, maintenance, termination?
4. Can I prove a recursive algorithm by induction on input size?
5. Can I solve a recurrence without blindly applying Master theorem?
6. Can I explain heap, hash table, and dynamic array using representation invariants?
7. Can I distinguish worst-case, expected-case, average-case, and amortized analysis?
8. Can I prove BFS shortest paths with a layer invariant?
9. Can I write an exchange argument for interval scheduling?
10. Can I define DP state, recurrence, base case, computation order, and reconstruction?
11. Can I define sample space and failure event for a randomized algorithm?
12. Can I explain why a lab output is not a proof?
