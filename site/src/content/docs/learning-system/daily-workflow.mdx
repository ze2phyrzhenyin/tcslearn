---
title: Daily Workflow
description: A concrete daily study procedure.
---

Follow this sequence every study day.

## 1. Read Today's Goal

Open the current day page and identify the learning goals, prerequisites, and required exercises.

## 2. Copy Definitions

Write every definition by hand. Include domain, variables, quantifiers, example, and non-example.

## 3. Redo Examples

Close the note and reconstruct the minimal examples. If the example is algorithmic, name input, output, invariant, correctness idea, and complexity variable.

## 4. Do Basic Problems

Start with Basic exercises. Do not skip them. They expose whether definitions are stable.

## 5. Write Proofs

For each proof:

1. Statement.
2. Definitions used.
3. Assumptions.
4. Goal.
5. Strategy.
6. Proof.
7. Step check.
8. Common mistake.

## 6. Compare with Solutions

Open solutions only after your attempt. Mark exactly where your reasoning diverged.

## 7. Record Mistakes

Update `state/mistakes_log.md`. Include the mistake, why it was wrong, the correct idea, and a repair exercise.

## 8. Review Flashcards

Use flashcards for exact definitions, theorem assumptions, proof templates, and recurring traps.

## 9. Update State

If something remains unclear, update `state/open_questions.md`. If the issue is proof-specific, update `state/proof_weaknesses.md`.

## 10. Prepare the Next Codex Prompt

Use `context/next_codex_prompt.md` only after you have concrete attempts or mistakes to analyze.
