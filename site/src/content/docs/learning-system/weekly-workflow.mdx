title: Weekly Workflow
description: How to run a full study week.
---

## Generate the Plan

Use `prompts/01_generate_week.md` to create a weekly plan, daily notes, problem set, solutions, labs, review materials, and state updates.

## Study the Week

Work through each day in order. Do not jump to advanced modules until foundations are stable.

## Run Labs

Labs are for intuition. For every lab result, write:

> This experiment suggests ..., but it does not prove ...

## Review

At the end of the week:

1. Take the self-test under time pressure.
2. Classify mistakes by topic.
3. Redo failed proofs without looking.
4. Review flashcards.
5. Update state files.

## Diagnose Weaknesses

Ask Codex for diagnostic feedback using your mistakes, not just the topic name. Good feedback needs failed attempts.

## Generate Repair Work

Before generating the next week, ask for targeted repair drills if any of these are weak:

- quantifiers;
- induction;
- invariants;
- asymptotic definitions;
- probability spaces;
- reductions.

## Generate the Next Week

Only generate Week 2 after the Week 1 self-test and repair pass are complete.
