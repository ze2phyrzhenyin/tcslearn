## Purpose

Labs help you see patterns before or after proving them. They are useful for growth rates, recurrences, probability simulations, and small computational models.

## How to Run

From the repository root:

```bash
python3 labs/week01/asymptotics_experiments.py
python3 labs/week01/recurrence_solver_sandbox.py
python3 labs/week01/probability_simulations.py
python3 labs/week01/finite_automata_toy.py
```

## How to Read Output

Every lab result should be interpreted as evidence for intuition, not as a theorem. Write one sentence:

> This experiment suggests ..., but it does not prove ...

## How to Modify

Change sample sizes, seeds, or input examples one at a time. Keep assertions. If you add randomness, set a seed or explain the randomness source.

## How to Review

After running a lab, add any conceptual mistake to `state/mistakes_log.md` and any useful observation to the weekly review.
