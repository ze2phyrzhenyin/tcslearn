# Prompt Templates

These prompts are reusable. Copy one into a Codex session and fill the placeholders. Each prompt assumes Codex will read `AGENTS.md`, `context/current_context.md`, and the relevant docs before editing files.

Recommended order for a new cycle:

1. `01_generate_week.md`
2. `02_generate_day.md`
3. `03_generate_problem_set.md`
4. `04_generate_solutions.md`
5. `05_generate_lab.md`
6. `09_weekly_retrospective.md`
7. `10_next_prompt_builder.md`
