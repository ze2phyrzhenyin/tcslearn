# 06 Generate Review Pack

```text
请读取：
- AGENTS.md
- context/current_context.md
- state/mistakes_log.md
- state/proof_weaknesses.md
- state/open_questions.md
- review/flashcards.md
- 当前 week notes 和 exercises

目标：
为 {week_or_day} 生成 review pack。

输出：
- review/weekly_reviews/{target}.md 或追加到现有 review 文件
- review/flashcards.md 新增高价值 cards
- state/next_actions.md 更新 repair tasks

内容：
- definitions to recall
- proof skeletons to rewrite
- common mistakes
- repair drills
- self-test
- next action priorities

不要引入新主题，除非是修补当前 blocker 所必需。
```
