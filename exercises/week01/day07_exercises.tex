\section*{Instructions}
Separate problem statements from algorithms. For reductions, name source and target problems.

\begin{enumerate}[label=\textbf{D7.\arabic*.}]
\item Formalize: given a list of integers, decide whether any value appears twice.

\item Formalize: given strings $p,t$, decide whether $p$ occurs in $t$.
\item Let $\Sigma=\{0,1\}$. Define the language of strings ending in 01 and list all members of length at most 3.
\item Define a language for even-length binary strings.
\item Draw or specify a DFA for binary strings with an even number of 1s.
\item Specify a DFA for strings over $\{a,b\}$ ending in $ab$.
\item Give a reduction intuition from duplicate detection to sorting.
\item Give a reduction intuition from membership in a finite set to dictionary lookup.
\item Write a theorem statement for binary search correctness.
\item Write a proof roadmap for the theorem in the previous exercise.
\item Explain why encoding integers in unary versus binary can change input size.
\end{enumerate}
